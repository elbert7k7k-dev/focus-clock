# Focus Clock · 专注小闹钟

一个用 Swift（苹果原生编程语言）和 AppKit（Mac原生界面框架）编写的本地专注计时工具。顶部显示完整小闹钟、右侧计时数字、开始／暂停按钮和今日累计入口；不需要图片、账号、服务器或第三方依赖包。

顶部小条是 **NSPanel（原生浮层窗口）**，位于菜单栏区域，**不是系统菜单栏状态项**。可以在允许的顶部安全区域内横向拖动。位置按屏幕安全区域比例保存，屏幕变化后重新适配；实际位置和可点击性仍须在使用的Mac上确认。

## 功能

- 倒计时：默认25分钟，可设置1—180整数分钟，提供30分钟快捷入口。
- 正计时：从零累计；随时开始、暂停、继续或结束。
- 顶部快捷开始／暂停／继续保留本轮进度；点击“累计”会先暂停，再打开记录窗口，关闭记录窗口不会自动继续。
- 只有专注倒计时和正计时的实际运行时间计入记录。暂停、5分钟休息和10秒体验不计入。
- 今日、本周（周一开始）、本月的真实时长和明细；累计专注、单日最高、最长单次、当前连续天数、最长连续天数和累计次数。
- 过去53周的每日活动格：灰色为零，蓝色按实际时长分档。鼠标移入小格显示日期、星期和当天专注时长，移开收起。
- 到点提醒支持提示音、系统语音和静音；提示音1—10声，语音文案1—120字，只使用本机可用声音和已安装人声。
- 记录和偏好保存在本机；正常退出后记录保留，重开回到25:00未开始。没有登录项或后台辅助程序。

## 使用条件

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS 13及以上 |
| 芯片 | Apple Silicon（苹果芯片，arm64）或Intel（英特尔芯片，x86_64） |
| 编译工具 | 已安装Apple Command Line Tools（苹果命令行开发工具），Swift 5.9及以上 |
| 依赖 | 系统框架；不需要Homebrew、Python、Node.js或外部依赖包 |
| 构建方式 | 在目标Mac本机编译，得到适配当前架构的应用 |

最低部署版本和架构支持是工程目标，不代表所有Mac和macOS版本都已实测。当前构建脚本默认生成本机架构版本，不是同时包含两种架构的通用二进制文件。开发者可用`zsh build.command arm64`或`zsh build.command x86_64`分别构建到`dist/arm64`或`dist/x86_64`；交叉编译不代表另一芯片实际运行通过。云电脑可以准备源码，不能代替目标Mac完成编译、显示、鼠标点击和声音验收。

3. 在终端进入解压后的源码目录，再依次运行：

```sh
zsh ./check.command
```

## 第一次运行

1. 确认顶部实际能看到完整闹钟，计时数字在闹钟右边。
2. 点击顶部`▶`开始，点击`Ⅱ`暂停，再次点击继续；点击闹钟／时间展开控制面板。
3. 拖动闹钟／时间区域调整横向位置，避开自己经常使用的菜单和其他图标。
4. 打开控制面板，先选“10秒体验”检查暂停、继续和到零状态。体验不写专注记录，也不播放专注完成提醒。
5. 需要检查真实记录和提醒时，设置1分钟专注倒计时；在“到点提醒”中保存并试听自己的提示音次数或语音，再实际运行到点。
6. 点击“累计”查看记录。今天的蓝格应显示实际专注时长；灰格应显示对应日期和“专注0秒”。

“暂停”保留本轮；“结束”停止本轮；“重置”和切换模式回到相应模式的初始状态。已经实际发生的专注记录保留，不会因为重置当前计时而被抹除。

系统发出休眠事件时，应用会暂停并保存；唤醒后需手动继续。应用退出或电脑关闭期间不会计入专注，也不会在离线期间继续提醒。本工具不是系统级闹钟服务。

## 数据与卸载

应用使用独立的本地目录，不导入开发原型或其他软件的记录：

```text
~/Library/Application Support/FocusClockLocal/focus-history.json
~/Library/Preferences/io.github.focusclock.local.plist
```

`~`表示当前使用者的个人文件夹。第一项为记录，第二项为本应用偏好，具体写入由macOS偏好系统管理。记录每约5秒保存检查点，暂停、结束和正常退出时也保存；异常终止可能丢失最后一个未保存区间，不补算离线时间。格式损坏或不支持的记录不会被自动覆盖。

卸载时，先在控制面板点击“退出”，再把自己构建的`专注小闹钟.app`移到废纸篓。源码目录和`.build`缓存可按需要保留或删除。记录与偏好默认保留，若要一并移除，由本人确认后处理上面两处**本应用专用路径**。不要删除整个`Application Support`或`Preferences`目录。

更多细节见[隐私说明](PRIVACY.md)与[验证范围](VALIDATION.md)。

## 常见问题

**顶部看不到或点击没有反应**：先确认打开的是当前构建的应用，且没有另一个旧版浮层占据相同位置。应用没有Dock（程序坞）常驻图标。屏幕、全屏空间、菜单自动隐藏和其他置顶工具可能影响实际显示，应在当前环境亲自检查；不要以导出的控件图片或窗口坐标代替实际看到和点击。

**听不到提示音或语音**：检查当前Mac的声音输出、音量和已安装人声，并使用“试听”验证。应用只检测本机资源，不自动下载声音。不同时代的Mac或系统不保证提供相同人声和提示音。

**记录和预期不同**：先确认使用的是专注倒计时或正计时；休息、体验、暂停和离线时间不计入。日、周、月按当前系统日历与时区划分；跨天会分到对应日期。同一轮暂停再继续仍按同一会话累计，最长单次不把暂停间隔算进去。

**为什么没有一键安装器**：此版本采用目标Mac本机构建，减少预编译文件、架构和签名差异。构建成功仍需要进行本机验收；不承诺任何自动化助手在所有环境一次完成。
