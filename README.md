# Focus Clock · 专注小闹钟

> **版本状态：1.1.0 / 构建号3已完成本机8套184组805项自动测试、arm64构建与严格签名，以及内置轻音乐的部分界面操作验收，正在准备公开发布。** 固定源码提交须发布后回读确认，初装／升级提示词随后更新；当前 [DOUBAO_PROMPT.txt](DOUBAO_PROMPT.txt)仍指向历史1.0，不能用它获取本次音乐版。新2曲尚未取得本人实听确认；下方构建号2的168组731项及本人听感另保留历史身份。

一个用 Swift（苹果原生编程语言）和 AppKit（Mac原生界面框架）及AVFoundation（系统音频框架）编写的本地专注计时工具。顶部显示完整小闹钟、右侧计时数字、开始／暂停按钮和今日累计入口；不需要图片、账号、服务器或第三方依赖包。

顶部小条是 **NSPanel（原生浮层窗口）**，位于菜单栏区域，**不是系统菜单栏状态项**。可以在允许的顶部安全区域内横向拖动。位置按屏幕安全区域比例保存，屏幕变化后重新适配；实际位置和可点击性仍须在使用的Mac上确认。

## 功能

- 倒计时：默认25分钟，可设置1—180整数分钟，提供30分钟快捷入口。
- 正计时：从零累计；随时开始、暂停、继续或结束。
- 顶部快捷开始／暂停／继续保留本轮进度；点击“累计”会先暂停，再打开记录窗口，关闭记录窗口不会自动继续。
- 只有专注倒计时和正计时的实际运行时间计入记录。暂停、5分钟休息和10秒体验不计入。
- 今日、本周（周一开始）、本月的真实时长和明细；累计专注、单日最高、最长单次、当前连续天数、最长连续天数和累计次数。
- 过去53周的每日活动格：灰色为零，蓝色按实际时长分档。鼠标移入小格显示日期、星期和当天专注时长，移开收起。
- 到点提醒保留系统语音和静音。1.1新增本地合成叮铃闹钟音、1—10声及独立提醒音量；语音文案1—120字，只使用已安装人声。
- 1.1新增多个本地专注歌单：拖入音乐、多首音频、显式选择的音乐文件夹或本地M3U清单，支持列表循环／单曲循环、上一首／下一首、播放／暂停和独立音乐音量。
- 构建号3附带“内置轻音乐”2曲：Calm Theme（pebonius，完整117.202秒）及Heavenly Loop（isaiah658，作者提供的33.652秒短循环）。均为CC0（公共领域贡献）；来源与转码说明见[音频许可清单](Resources/BundledMusic/CREDITS.txt)。首次在后台复制到自身曲库，不自动播放，重开不重复，主动删除后不自动复活；不包含私人9首商业歌曲。
- 1.1可选“随专注开始／暂停”，默认关闭；音乐播放不作为专注计时依据。到点提醒期间自动降低背景音乐音量，提醒结束或停止后恢复所设音量，不把已暂停的音乐重新启动。
- 1.1可把自己选择或拖入的一首本地音乐设为到点提醒：完整播放一次，可随时停止，不把“1—10声”重复次数套到整首音乐上。
- 记录和偏好保存在本机；正常退出后记录保留，重开回到25:00未开始。没有登录项或后台辅助程序。

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS 13及以上 |
| 芯片 | Apple Silicon（苹果芯片，arm64）或Intel（英特尔芯片，x86_64） |

## 第一次运行

1. 确认顶部实际能看到完整闹钟，计时数字在闹钟右边。
2. 点击顶部`▶`开始，点击`Ⅱ`暂停，再次点击继续；点击闹钟／时间展开控制面板。
3. 拖动闹钟／时间区域调整横向位置，避开自己经常使用的菜单和其他图标。
4. 打开控制面板，先选“10秒体验”检查暂停、继续和到零状态。体验不写专注记录，也不播放专注完成提醒。
5. 需要检查真实记录和提醒时，设置1分钟专注倒计时；在“到点提醒”（1.1为“声音设置”）中保存并试听自己的闹钟次数或语音，再实际运行到点。
6. 点击“累计”查看记录。今天的蓝格应显示实际专注时长；灰格应显示对应日期和“专注0秒”。

“暂停”保留本轮；“结束”停止本轮；“重置”和切换模式回到相应模式的初始状态。已经实际发生的专注记录保留，不会因为重置当前计时而被抹除。

系统发出休眠事件时，应用会暂停并保存；唤醒后需手动继续。应用退出或电脑关闭期间不会计入专注，也不会在离线期间继续提醒。本工具不是系统级闹钟服务。

## 1.1：载入音乐与提醒

构建号3本轮实际运行`test.command`，8套184组805项全部退出0；本机arm64构建与严格签名校验通过。原生界面已核“内置轻音乐”两曲名称／时长（1:57与0:34）和未自动播放，实际操作Calm Theme播放、下一首Heavenly Loop、暂停。原有真实专注记录与暂停后备份逐字节相同，已有跟随计时及35%音乐音量偏好保留；不把保留的本人选项误当新安装默认值。新2曲没有本人实听确认，完整长时、休眠、其他Mac仍未测，详见[验证范围](VALIDATION.md)。

以下为同源1.1.0／构建号2的历史证据：当时`test.command`实际7套、168组731项通过，arm64构建与严格签名通过；原生界面操作及本人音乐／三声闹钟听感已确认。构建号3的本轮结果见上一段，不能沿用上述个人9曲的播放或听感作为新2曲实听结论。当前源码不打包这9曲。

构建号2的独立静音短时检查另验证自然接曲、单曲循环、暂停、提醒次数及降低音乐音量后恢复；这不计入上面的自动测试数，也不冒充实听。自定义提醒通过本地1秒样本选择、导入、保存并试听且无错误，但没有使用者单独实听确认。本次真实跨窗口拖拽、完整38分29秒歌单、完整25／30分钟、休眠和其他Mac尚未实测；完整证据与限制见[验证范围](VALIDATION.md)。

1. 在控制面板点击“专注歌单”，创建或选择歌单，点击“载入音乐”，也可以把本机音乐拖到载入区。支持MP3、M4A、WAV、AIFF、AIF、CAF；实际文件还须能被本机系统解码。
2. 可选择音乐文件夹，工具只载入该文件夹第一层的支持音频，不递归搜寻其他目录；多文件按选择／清单顺序进入歌单，文件夹按文件名排序。UTF-8（通用文字编码）的本地M3U／M3U8清单仅接受指向其所在文件夹范围内的本机音频，建议用相对路径；不接受在线歌单链接、流媒体、上级路径或符号链接。
3. 每批最多100首、单文件最多512MB、合计最多2GB。导入会把音频复制到本工具自己的数据目录；原文件保留。没有自动导入音乐服务账号或扫描整机媒体库。
4. 选择列表循环或单曲循环并调整音乐音量，点击播放。可选开启“随专注开始／暂停”；关闭时，音乐与专注计时分别操作。默认载入或打开歌单不会自行播放，重新启动应用也不会自动播放；已主动开启跟随时按当前专注状态控制音乐。
5. 在控制面板点击“声音设置”，选择闹钟、自定义音乐、语音或静音。闹钟可设1—10声；自定义音乐可点击“选择音频”或拖入一首本机音频，点击“保存”后用于到点提醒，点击“保存并试听”检查实际听感。
6. 提醒音量只调整本应用，不改变Mac系统音量。自定义提醒整曲播放一次；“停止提醒”可以提前停止。系统静音、输出设备或系统音量较低仍会影响最终听感。

除随附的2首CC0示范音乐外，个人歌单与自定义提醒由使用者明确选择本地音频提供。开源工程不附带、上传或公开分发其他商业音乐；把私人项目中的歌曲用于本机，不代表获得对外分发许可。

## 数据与卸载

应用使用独立的本地目录，不导入开发原型或其他软件的记录：

```text
~/Library/Application Support/FocusClockLocal/focus-history.json
~/Library/Application Support/FocusClockLocal/audio-library.json     # 1.1歌单元数据
~/Library/Application Support/FocusClockLocal/Audio/                 # 1.1内置及个人导入音频副本
~/Library/Preferences/io.github.focusclock.local.plist
```

`~`表示当前使用者的个人文件夹。`focus-history.json`为专注记录；`audio-library.json`为1.1歌单元数据；`Audio/`只存本工具的内置及个人导入副本；最后一项为本应用偏好，由macOS偏好系统管理。1.1沿用原有专注记录与提醒偏好，新增音量等缺省值，不导入其他工具的数据。记录每约5秒保存检查点，暂停、结束和正常退出时也保存；异常终止可能丢失最后一个未保存区间，不补算离线时间。格式损坏或不支持的记录不会被自动覆盖。

卸载时，先在控制面板点击“退出”，再把自己构建的`专注小闹钟.app`移到废纸篓。源码目录和`.build`缓存可按需要保留或删除。记录与偏好默认保留，若要一并移除，由本人确认后处理上面的**本应用专用数据根目录`FocusClockLocal`及自身偏好文件**。不要删除整个`Application Support`或`Preferences`目录。

更多细节见[隐私说明](PRIVACY.md)与[验证范围](VALIDATION.md)。

## 常见问题

**顶部看不到或点击没有反应**：先确认打开的是当前构建的应用，且没有另一个旧版浮层占据相同位置。应用没有Dock（程序坞）常驻图标。屏幕、全屏空间、菜单自动隐藏和其他置顶工具可能影响实际显示，应在当前环境亲自检查；不要以导出的控件图片或窗口坐标代替实际看到和点击。

**听不到提示音或语音**：检查当前Mac的声音输出、音量和已安装人声，并使用“试听”验证。1.1可在“声音设置”调整提醒音量和试听；闹钟音由本机生成，音乐由本人导入，人声来自本机已安装资源。不自动下载声音，不改变系统音量；不同Mac或系统不保证提供相同人声。

**记录和预期不同**：先确认使用的是专注倒计时或正计时；休息、体验、暂停和离线时间不计入。日、周、月按当前系统日历与时区划分；跨天会分到对应日期。同一轮暂停再继续仍按同一会话累计，最长单次不把暂停间隔算进去。

**为什么没有一键安装器**：此版本采用目标Mac本机构建，减少预编译文件、架构和签名差异。构建成功仍需要进行本机验收；不承诺任何自动化助手在所有环境一次完成。
